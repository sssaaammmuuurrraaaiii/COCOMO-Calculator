# COCOMO-Калькулятор
[ENG]
This GitHib repository contains a ready-to-use COCOMO Calculator written in the object-oriented programming language C#.
There is support for exporting the obtained data to Excel (for now only for the Basic model).

For non-commercial use.

P.S. Before using this tool, it is advisable to be familiar with the basic knowledge on this topic at the link below:
https://www.educative.io/answers/what-is-the-cocomo-model 

ENJOY!!!
